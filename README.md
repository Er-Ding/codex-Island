# Codex Island

现已增加 **Windows 原生版（0.3.1）**：使用 C# / WPF，支持真实额度、透明置顶窗口、托盘、位置保存和按显示器调整大小。本版改为鼠标移入立即展开，并统一额度菜单与面板的字体、配色和间距。运行与构建见 [Windows 说明](windows/README.md)，架构梳理见 [Windows 适配说明](docs/WINDOWS_PORT.md)。下文为现有 macOS 版本说明。

一个放在 MacBook 摄像头附近的 Codex 额度小工具。平时只露出周期与剩余比例，鼠标移入后展开查看详情。使用这台 Mac 已登录的 Codex 账号。

## 打开

双击 `dist/Codex Island.app`。菜单栏会出现一个小柱状图图标，可隐藏、重新显示或退出。

- **悬停**：进入整个灵动岛范围即可展开，包括中央留白与边缘；离开整个面板后稍等再收起。
- **点击顶部**：打开并固定，或收起。
- **图钉**：保持展开；向上箭头收起。
- **标题旁的小箭头**：切换主额度与其他模型的额度。
- **刷新按钮**：立即读取；后台默认每 30 秒读取一次。

有刘海时避开摄像头，文字放在两侧；没有刘海时显示为顶部居中的小胶囊。优先放在内置屏幕。应用没有 Dock 图标。

## 调整并固定位置（0.2.0）

无刘海屏幕的默认位置已上移到紧贴屏幕顶部。

1. 在展开面板底部点“调整位置”图标，或从菜单栏小柱状图中选择“调整位置…”。
2. 按住“拖动调整位置”区域，拖到想要的位置，也可以拖到其他显示器。
3. 点“完成”保存并锁定。平时不会被误拖动，重启后恢复保存的位置。

点 X 可取消这次调整。菜单栏的“恢复默认位置”会回到顶部居中。调整过程中暂停悬停展开，方便拖动；靠近屏幕边缘时，展开面板会收回屏幕内。自选位置如果碰到摄像头，会避让到其下方。

位置只保存在当前 Mac 上；另一台 Mac 可以独立调整。显示器暂时断开时会在可用屏幕上显示，不会把已保存的显示器设置覆盖掉。

位置保存、恢复、边界和刘海避让可用 `bash scripts/test-placement.sh` 检查。

本机已通过 18 项位置检查和 8 项悬停检查，并实际检查了拖动、完成保存、取消调整及退出后保存值仍在。Mac mini 可用 `dist/Codex-Island-0.2.0-Mac-mini.zip` 替换旧应用；本次测试位置不会随应用包传到另一台 Mac。

## 数据如何显示

百分比表示**剩余额度**。25% 及以下显示橙色，10% 及以下显示红色。周期长度以 Codex 实际返回的内容为准：账号只有一个周期时只显示一张卡片。不同类别的额度分开显示。

读取失败时保留上次成功的数据，并显示橙点、错误提示和上次更新时间。尚未拿到数据时显示横线。到了预计恢复时间也不会自行假定额度已满，要等下一次读取确认。

后台轮询间隔为 30 秒，并非保证逐秒更新。展开面板会额外刷新；网络连续失败时逐步延长重试间隔，最多 5 分钟。唤醒后重新定位并刷新。

## 运行条件

- macOS 13 或更新版本；当前构建为 Apple 芯片版本。
- 已安装并使用 ChatGPT 账号登录 Codex。应用自动寻找 ChatGPT/Codex 桌面应用自带的程序或常见安装位置的命令行程序。
- API 密钥登录可能没有订阅额度，应用会提示当前无法读取。

小工具通过本机 Codex 的 `account/rateLimits/read` 查询额度，只做初始化与额度读取，不创建聊天任务。登录信息仍由 Codex 自己管理，小工具不读取或保存登录密钥，也不读取聊天记录。Codex 自身启动时会打开它的本地状态数据库。

这是本地可运行的小样，采用本机签名，尚未作为面向其他用户分发的正式应用发布。自动开机启动和声音通知尚未加入。多屏定位已实现，所有外接屏和全屏应用组合仍需要实际使用检查。

## 开发

源码采用 SwiftUI 和 AppKit，不依赖第三方软件包。有 Apple 命令行开发工具即可构建。

```bash
bash scripts/build-app.sh
```

测试：

```bash
bash scripts/test.sh
```

诊断真实额度（只输出额度类别、周期、剩余比例及更新时间）：

```bash
"dist/Codex Island.app/Contents/MacOS/CodexIsland" --check-quota
```

查看屏幕尺寸与刘海避让尺寸：

```bash
"dist/Codex Island.app/Contents/MacOS/CodexIsland" --diagnose-screen
```

演示数据仅在显式传入 `--demo` 时启用，界面会标明“演示数据”；默认运行始终读取真实额度。

接口依据：[OpenAI 官方 Codex App Server 文档](https://learn.chatgpt.com/docs/app-server)。
