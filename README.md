# Codex Island

现已增加 **Windows 原生版（0.3.1）**：使用 C# / WPF，支持真实额度、透明置顶窗口、托盘、位置保存和按显示器调整大小。本版改为鼠标移入立即展开，并统一额度菜单与面板的字体、配色和间距。运行与构建见 [Windows 说明](windows/README.md)，架构梳理见 [Windows 适配说明](docs/WINDOWS_PORT.md)。下文为现有 macOS 版本说明。

一个放在 MacBook 摄像头附近的 Codex 额度与任务小工具。平时显示周期、剩余比例和任务状态，鼠标移入后展开查看详情。使用这台 Mac 已登录的 Codex 账号。

当前使用步骤以本文为准；修改原因、涉及文件、验证状态及未发布内容见 [更新日志](CHANGELOG.md)，后续维护约定见 [AGENTS.md](AGENTS.md)。源码变化不会自动更新已有的 `dist` 应用，更新后请按 [构建与重新运行](#构建与重新运行) 生成新版。

## 打开

双击 `dist/Codex Island.app`。菜单栏会出现一个小柱状图图标，可隐藏、重新显示或退出。

- **悬停**：进入整个灵动岛范围即可展开，包括中央留白与边缘；离开整个面板后稍等再收起。
- **点击顶部额度区域**：展开并切换固定状态；取消固定后，移出面板才会自动收起。
- **拖动顶部**：普通模式也可按住顶部直接移动，松手保存；双击顶部额度区域恢复默认位置。
- **任务徽标**：显示进行中任务数量；点击打开优先任务，没有任务时展开列表。
- **图钉**：保持展开；向上箭头收起。
- **标题旁的小箭头**：切换主额度与其他模型的额度。
- **额度刷新按钮**：立即读取额度；额度后台默认每 30 秒读取一次。任务状态使用独立的自动同步流程。

有刘海时避开摄像头，文字放在两侧；没有刘海时显示为顶部居中的小胶囊。优先放在内置屏幕。应用没有 Dock 图标。

## 调整并保存位置

无刘海屏幕的默认位置已上移到紧贴屏幕顶部。

1. 在展开面板底部点“调整位置”图标，或从菜单栏小柱状图中选择“调整位置…”。
2. 按住“拖动调整位置”区域，拖到想要的位置，也可以拖到其他显示器。
3. 点“完成”保存，重启后恢复保存的位置。普通模式仍支持拖动顶部移动；固定展开状态不等于锁定位置。

点 X 可取消这次调整。菜单栏的“恢复默认位置”会回到顶部居中。调整过程中暂停悬停展开，方便拖动；靠近屏幕边缘时，展开面板会收回屏幕内。自选位置如果碰到摄像头，会避让到其下方。

位置只保存在当前 Mac 上；另一台 Mac 可以独立调整。显示器暂时断开时会在可用屏幕上显示，不会把已保存的显示器设置覆盖掉。

位置保存、恢复、边界和刘海避让可用 `bash scripts/test-placement.sh` 检查。

早期 0.2.0 文档曾记录 18 项位置检查、8 项悬停检查及本机拖动操作通过。这些是历史结果，不覆盖后续顶部事件、动画及任务跳转修改，也不能代替 Mac mini 的实际交互验证。旧 `dist/Codex-Island-0.2.0-Mac-mini.zip` 不应当作包含最新源码的安装包；当前状态见 [更新日志](CHANGELOG.md)。

## 任务与会话跳转

请保持 Codex Desktop 运行。浮动岛展示 Desktop 已加载并同步的任务，包括可用的远端来源；连接断开时保留任务并标记待同步，不把它当作任务已完成。

- 缩略徽标优先打开等待操作的任务，其次是运行中的任务；展开列表可以逐行选择。
- 普通 Desktop 会话通过会话链接打开；VS Code 和 Terminal/iTerm2 会尝试定位原窗口或页签，无法定位时尝试在 Desktop 打开同一会话，并显示原因。
- 侧边聊天先打开所属主会话，再通过辅助功能匹配已有页签。它使用首次提问形成的页签名称，可能与任务自动标题不同。
- 右侧面板折叠时会尝试恢复已有标签页；**放在底部面板的侧边聊天，需要先手动展开底部面板**。
- 同名页签、无法取得页签名称或不支持的所属页面会提示手动处理。定位期间切换到其他窗口或应用，会停止本次选择。

侧边聊天定位修改目前仅完成源码和静态检查，尚未构建、实机验证；完整限制及后续反馈记录在 [更新日志](CHANGELOG.md)。

## 数据如何显示

百分比表示**剩余额度**。25% 及以下显示橙色，10% 及以下显示红色。周期长度以 Codex 实际返回的内容为准：账号只有一个周期时只显示一张卡片。不同类别的额度分开显示。

读取失败时保留上次成功的数据，并显示橙点、错误提示和上次更新时间。尚未拿到数据时显示横线。到了预计恢复时间也不会自行假定额度已满，要等下一次读取确认。

后台轮询间隔为 30 秒，并非保证逐秒更新。展开面板会额外刷新；网络连续失败时逐步延长重试间隔，最多 5 分钟。唤醒后重新定位并刷新。

## 运行条件

- macOS 13 或更新版本；当前构建为 Apple 芯片版本。
- 已安装并使用 ChatGPT 账号登录 Codex。应用自动寻找 ChatGPT/Codex 桌面应用自带的程序或常见安装位置的命令行程序。
- API 密钥登录可能没有订阅额度，应用会提示当前无法读取。

额度通过本机 Codex 的 `account/rateLimits/read` 查询。任务功能另外读取 Desktop 的本地任务流，从快照中提取标题、状态、进度和导航信息；侧边聊天定位还会从首条提问提取页签名称。完整提问上下文、原始推理、工具参数和终端输出不作为任务缓存保存。VS Code／终端定位可能读取本机会话元数据、窗口日志及进程关联信息。

小工具不发起聊天任务、不发送提示词、不自行建立 SSH 连接。登录信息仍由 Codex 自己管理，小工具不读取或保存登录密钥。Codex 自身启动时会打开它的本地状态数据库。

这是本地可运行的小样，采用本机签名，尚未作为面向其他用户分发的正式应用发布。自动开机启动和声音通知尚未加入。多屏定位已实现，所有外接屏和全屏应用组合仍需要实际使用检查。

## 首次使用与权限

权限按实际使用的功能授予；“辅助功能”和“自动化”是两个不同的设置项。

| 使用功能 | 需要的条件或权限 | 首次使用操作 |
| --- | --- | --- |
| 额度读取、任务列表、普通 Desktop 会话链接 | Codex 已登录；任务列表需要 Desktop 正在运行 | 不要求为这些功能额外开启辅助功能权限 |
| **侧边聊天页签定位** | **辅助功能** | 在 **系统设置 → 隐私与安全性 → 辅助功能** 中允许 **Codex Island**，然后再次点击任务 |
| Terminal / iTerm2 原页签定位 | 自动化：允许控制实际使用的终端应用 | 按系统提示允许；若之前拒绝，在 **系统设置 → 隐私与安全性 → 自动化 → Codex Island** 中允许对应终端 |
| VS Code 原窗口定位 | VS Code 与目标会话窗口仍在运行，且可确认窗口来源 | 无法确认时会提示并尝试回退 Desktop |

如果“辅助功能”列表没有 Codex Island，点击 `+`，选择刚构建的 `dist/Codex Island.app`，开启开关。授权后回到 Desktop，再点击浮动岛任务重试。换一台 Mac 后，也需要在那台机器上完成相应授权。

侧边聊天定位会读取 Desktop 的辅助功能界面结构并选择已有页签；终端定位会通过自动化选择已有 Terminal/iTerm2 页签，不会向终端输入命令。

### 常见现象

| 现象 | 处理方式 |
| --- | --- |
| 更新源码后行为没有变化 | 退出旧浮动岛，重新构建并运行新生成的应用；已有应用包不会自动更新 |
| 侧边聊天只打开 Desktop，或提示未定位 | 确认运行新版、已授予辅助功能权限、所属主会话仍可打开；底部面板中的聊天先手动展开面板 |
| 提示页签同名或无法匹配 | 手动选择目标页签；特殊 Markdown/HTML、超长首条提问或缺失首条历史可能影响名称匹配 |
| 提示窗口焦点变化 | 保持 Desktop 在前台，重新点击浮动岛任务，定位期间不要切换到其他窗口 |
| 终端定位提示权限被拒绝 | 检查“自动化”中的对应终端授权；仅开启“辅助功能”不能替代它 |
| 任务一直待同步 | 检查 Desktop 是否运行、对应设备是否连接，并刷新任务；列表只覆盖已加载且可同步的任务 |

## 构建与重新运行

源码采用 SwiftUI 和 AppKit，不依赖第三方软件包。有 Apple 命令行开发工具即可构建。

每次更新源码后，先从浮动岛菜单退出旧程序，再在仓库根目录执行：

```bash
bash scripts/build-app.sh && open "dist/Codex Island.app"
```

本机仓库目录为 `/Volumes/disk2/Codex-Island/codex-Island`。脚本会重新构建、生成应用并执行本机签名；`&&` 确保构建失败时不会误打开旧应用。只修改源码不会更新正在运行的进程。

应用版本号目前由构建脚本固定填写，不能仅凭版本号判断是否包含某次源码修改；修改日期和状态以更新日志为准。迁移到另一台机器时应使用重新构建后的应用，并检查该机器上的权限。

## 开发与诊断

以下为手动执行入口，不代表已针对当前源码运行；验证结果应记录到更新日志的对应条目。

测试：

```bash
bash scripts/test.sh
```

诊断真实额度（只输出额度类别、周期、剩余比例及更新时间）：

```bash
"dist/Codex Island.app/Contents/MacOS/CodexIsland" --check-quota
```

查看屏幕尺寸与刘海避让尺寸：

```bash
"dist/Codex Island.app/Contents/MacOS/CodexIsland" --diagnose-screen
```

演示数据仅在显式传入 `--demo` 时启用，界面会标明“演示数据”；默认运行始终读取真实额度。

接口依据：[OpenAI 官方 Codex App Server 文档](https://learn.chatgpt.com/docs/app-server)。
