# Codex Island · Windows

把 Codex 剩余额度放在桌面上，抬眼就能看到。

Codex Island 是一个轻量的桌面悬浮工具。平时以小胶囊显示额度和任务数量，鼠标移入即刻展开，查看不同模型的剩余比例、恢复时间，以及任务进展。点击任务可以回到对应会话。

![Codex Island 展开面板](windows/assets/island-preview.png)

*截图为演示数据；运行时默认显示你当前 Codex 账号的实际额度。*

## 能做什么

- **随时查看额度**：显示剩余百分比、额度周期和预计恢复时间。
- **切换额度类别**：在标题旁的菜单中切换账号返回的不同模型额度。
- **悬停展开、点击固定**：快速查看，也可以让详情一直留在桌面上。
- **按住顶部移动**：缩略或展开时均可按住顶部立即拖动，松开保存位置；双击额度区域即可复位。
- **查看任务进展**：显示 Desktop 已加载任务的标题、来源设备、执行状态、计划步骤和最新进展，优先提醒等待批准或回复的任务。
- **一键回到会话**：点击任务，打开 Desktop 会话，或尝试定位 VS Code、终端、侧边聊天的原入口。
- **后台自动更新**：定期刷新，也支持手动刷新；读取失败时保留上次的数据并提示。
- **托盘控制**：隐藏、重新显示、调整设置或退出，均可从任务栏通知区域操作。

## 开始使用

### 准备

- 在 Windows 本机安装 Codex，并使用有订阅额度的 ChatGPT 账号登录。
- 当前已验证的环境是 **Windows 11 x64**。推荐使用 `win-x64` 便携包。
- 标准便携包自带运行环境，无需另外安装 .NET 或开发工具。

仅在 WSL 内安装或登录 Codex，不能代替 Windows 本机登录。

### 打开程序

1. 获取 `Codex-Island-<版本>-win-x64.zip`，解压到你希望长期存放的位置。
2. 双击文件夹中的 **`CodexIsland.exe`**。
3. 等待首次读取完成。灵动岛会出现在屏幕顶部，任务栏通知区域会出现小柱状图图标。

发布包可查看仓库的 [Releases 页面](https://github.com/Er-Ding/codex-Island/releases)。若没有对应的发布包，可按 [构建说明](windows/docs/DEVELOPMENT.md) 从源码生成。

| 打开优先任务 | 点击顶部中间的任务徽标，优先打开等待操作的任务；没有任务时展开列表 |

### 调整位置

1. 将鼠标移入缩略悬浮框，使面板展开。
2. 在**最上方显示额度的横栏**按住鼠标左键并移动鼠标，悬浮框立即跟随，可拖到目标位置或另一块显示器。
3. 松开鼠标，位置自动保存。

不需要等待长按，缩略状态或展开动画期间也能按住顶部直接拖动。按住期间只要移动鼠标就会拖动；在额度区域原地松开则切换固定 / 取消固定。取消固定后，面板保持展开，鼠标移出后自动收起。拖动中按 Esc 或鼠标右键可取消，恢复已保存的位置。

托盘菜单也保留“调整位置…”作为备选：进入后拖动“拖动调整位置”区域，点击“完成”保存，或点击 × 取消。

保存后，重启仍会恢复位置。需要复位时，**双击顶部额度区域**，即可回到主屏顶部中央并收起，显示大小设置会保留。中间任务徽标用于打开任务，拖动徽标也能移动悬浮框。托盘菜单中的“恢复默认位置”继续可用。

### 调整大小

右键托盘图标 → **显示大小**，选择自动适配或 100%–200% 的大小。每块显示器可以使用不同的设置。

## 如何理解额度

- 百分比表示**剩余**，不是已使用。剩余不超过 25% 时显示橙色，不超过 10% 时显示红色。
- 周期和类别以账号实际返回的数据为准。只有一个周期时，面板只显示一张卡片。
- 后台通常每 30 秒更新一次。读取失败时会延后重试，你也可以点击刷新。
- 遇到连接问题，面板会保留上次成功的数据，并显示提示和上次更新时间。
- 到了预计恢复时间，仍需下一次成功读取才能确认额度已恢复。
- 周额度显示固定北京时间的具体刷新日期，例如“北京时间 9月18日 08:30 刷新”；其他周期继续显示剩余多久恢复。

## 任务与会话跳转

请保持 **Windows Codex Desktop** 运行。额度读取与任务同步相互独立：即使能读到额度，Desktop 关闭时任务列表仍可能无法连接。

- 列表覆盖 Desktop **已加载且可同步**的本地及远端任务，不是所有历史会话。任务状态独立自动同步，展开面板和刷新按钮也会触发更新。
- 启动顺序不限：先开始任务、再打开灵动岛，也会主动同步现有任务。首次回应较慢或连接恢复时会自动重试，无需重新开始任务。
- 绿色表示进行中，橙色表示等待批准或回复，灰色表示状态待同步。断开连接时保留上次任务，并标记待同步；只有确认结束后才移出列表。
- 有执行计划时显示已完成步骤和当前步骤；其他任务显示公开进展摘要，或正在执行命令、修改文件等状态。
- 顶部徽标优先打开等待操作的任务，其次是正在执行的任务。按下时确定目标，刷新期间不会改成另一个任务。

| 任务来源 | 点击后的行为 |
| --- | --- |
| Codex Desktop | 请求打开对应的已有会话 |
| VS Code | 可确认原窗口与会话时定位原入口，否则尝试在 Desktop 打开同一会话并显示原因 |
| Windows 终端 | 仅在原进程窗口或页签有唯一、可验证标识时定位；不能精确确认时回退 Desktop |
| 侧边聊天 | 先打开所属主会话，再匹配已有侧边页签；重名、页签未暴露、焦点变化或超时会显示提示 |

侧边聊天依赖 Desktop 的 Windows 辅助功能界面。右侧面板折叠时尝试恢复已有标签页；底部面板需要先手动展开。定位期间请保持 Desktop 在前台。以管理员权限运行的目标应用可能无法由普通权限的灵动岛操作，此时手动打开目标会话即可。

跨设备相同会话标识、WSL／SSH／tmux 等中转环境、关闭的终端页签，可能无法准确定位原入口。工具只打开已有会话或选择已有页签，不发送提示词、不执行终端命令，也不自行建立 SSH 连接。

## 常见问题

**提示未找到 Codex？** 先确认 Windows 版 Codex 能正常打开并已登录。随后右键托盘图标 →“选择 Codex 程序…”，选择本机的 `codex.exe`；也可以选择“自动查找 Codex”后重试。

**一直没有额度或只有横线？** 确认使用的是有订阅额度的 ChatGPT 账号，检查网络后点击刷新。API 密钥登录不一定提供这里显示的订阅额度。

**找不到悬浮窗？** 在任务栏右侧的隐藏图标区域找到小柱状图，点击它重新显示；如果位置不合适，选择“恢复默认位置”。再次启动程序也会显示已有窗口。

**怎样更新？** 先从托盘退出旧版，再解压新版替换程序文件。位置和大小保存在 `%LOCALAPPDATA%\CodexIsland\settings.json`，替换程序不会清除这些设置。

**会自动开机启动吗？** 当前不会自动设置开机启动，也没有内置自动更新。

**能看到额度，但任务一直待同步？** 确认 Windows Codex Desktop 正在运行，目标设备已连接，并在 Desktop 中加载目标会话后刷新。Desktop 更新可能改变任务接口；此时列表会提示兼容性或同步问题。

**先开始的任务没有出现在灵动岛里？** 请更新到 Windows 0.4.1 或更新版本。新版启动时会补读已有会话并请求当前状态；通常在几秒内显示，历史会话较多时会分批同步。已结束的历史会话不会计入运行任务。

**点击任务没有进入原窗口？** 查看任务区域的反馈。VS Code、终端和侧边页签只在能明确定位时自动选择；回退 Desktop 也只是请求打开会话，不代表原窗口已经被选中。

## 平台与分支

当前分支维护 `windows/` 下的 Windows 实现。macOS 最新开发在远端 `main` 的 `Sources/CodexIsland/`；本地 `macOS` 分支是早期隔离目录快照。

| 分支 | 平台目录 | 用途 |
| --- | --- | --- |
| `Windows` | `windows/` | Windows 版；当前使用指南对应此分支 |
| 远端 `main` | `Sources/CodexIsland/` | 当前 macOS 新功能来源 |
| 本地 `macOS` | `macos/` | 早期 macOS 隔离快照，尚未包含远端近期更新 |

本次按远端 `main` 的 `9c1b658` 同步功能到 Windows。远端目前没有 `macOS` 分支，不能把本地旧快照当作最新 macOS 版本。维护方法见 [开发说明](windows/docs/DEVELOPMENT.md#平台分支)，本次变更和验证状态见 [更新日志](CHANGELOG.md)。

需要构建、测试或排查问题，请阅读 [开发说明](windows/docs/DEVELOPMENT.md)。
